# StudyFlow

A responsive study workspace built with semantic HTML, modern CSS and vanilla JavaScript. Designed for GitHub Pages with an optional separate AI API server.

## Quick start
Open `index.html` directly, or use VS Code Live Server. No build step is required.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Project structure
See the source folders for styles, modular scripts, data, assets, and optional server code.

## Privacy
Study data is stored locally in this browser. The AI demo is offline by default. Never put API keys in frontend code.
